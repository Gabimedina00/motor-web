# Brief: motor-web

- Qué es: un motor genérico para construir sitios de comercios. Un solo código; cada cliente es una carpeta de datos y estilos.
- Para quién: comercios chicos y medianos que venden por redes y WhatsApp (gastronomía, insumos, estética, servicios, creativos).
- Cómo se edita: en código. Contenido y configuración en archivos del repo (JSON validado + Markdown), sin planillas ni paneles no-code. Sirve para aprender a programar y para cambiar rápido lo que pida un cliente.
- Acciones que resuelve: ver el catálogo con precios, armar un pedido y enviarlo por WhatsApp, pedir turno, contactar, ver ubicación y horarios.
- Cliente incluido: solo `_ejemplo`, ficticio, para probar y copiar. Ningún cliente real queda fijo en el motor.
- Fuera de alcance v1: pagos online, panel admin, cuentas de usuario.
- Próximo paso después del motor: Cromo Insumos como primer cliente real, en su propio hilo.
